# Принципы работы с базой

Первые шесть — те же, что в базовой версии; дальше — для расширенной структуры.

1. Знание живёт в файлах, не в чате. Чат умирает — файлы остаются.
2. Один файл — одна тема; маленькие файлы, понятные названия.
3. Агент пишет — я проверяю. Не глядя не принимаю.
4. Нет факта в базе — агент спрашивает, а не выдумывает.
5. Улучшить агента = поправить файл, а не «перенастроить чат».
6. Каждая сессия заканчивается записью (протокол — `session-end.md`).
7. `status.md` — честное состояние: что застряло, пишем прямо, не прячем
   в конец файла проекта. Агент читает его каждую сессию.
8. Всё новое встаёт на карту: создал файл — добавь строку в `HOME.md`,
   иначе файл потеряется.
9. Решения записываются с датой в `decisions/` — решённое не пересматриваем
   заново «с нуля», а начинаем с записанного.
10. Завершённое уходит в `_archive/` целиком; живая база не ссылается на архив.
