# OZON — Озоноразрушающие вещества

Проект по озоноразрушающим веществам (ОРВ).

## Правило сессий

- Каждая сессия по проекту ведётся и сохраняется под названием
  **«Ozon — ГГГГ-ММ-ДД»** (дата сохранения).
- В конце сессии сохраняем её под этим названием.
- В следующий раз продолжаем **в новой сессии с чистой историей** —
  предыдущую не переоткрываем.
