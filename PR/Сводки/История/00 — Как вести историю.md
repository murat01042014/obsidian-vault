# История сводок — как вести

Ведётся с 2026-10-06 (просьба Мурата). Каждая сводка (утро 08:50, вечер 16:50, Астана) **дописывает новые строки** в реестры ниже и обновляет [Статистику](Статистика.md). Ничего не удаляется; исправления — новой строкой/пометкой.

| Реестр | Что |
|---|---|
| [Назначения](Назначения.md) | министры, вице-министры, Правительство, АП (от заведующих отделами) |
| [Встречи](Встречи.md) | экологические и климатические встречи: РК, ЦА, мир |
| [Экопубликации](Экопубликации.md) | достижения и проблемы в экологии РК |
| [Таза Қазақстан](Таза Қазақстан.md) | всё по акции и проектному офису, только РК |
| [Статистика](Статистика.md) | счётчики по месяцам и темам |

Правила записи
- Одна строка = один факт. Дубли не писать (проверять по ссылке и названию).
- Колонка «Проверка»: **✔** (2+ источника или официальный), **1** (один источник), **?** (по выдержке поиска, не открыто).
- Дата — дата события/публикации; если неизвестна — «дата?», дата внесения — в колонке «Внесено».
- Тональность для публикаций: **Д** — достижение, **П** — проблема, **Н** — нейтрально.

Стиль сводок (указание Мурата, 06.10): коротко, только суть — одна строка на факт. Детали — по запросу.

Назначения (указание Мурата, 06.10): для каждого — **полное ФИО**, откуда пришёл (последняя должность), **кого сменил** и **по какой причине ушёл прежний** (отставка, перевод, освобождение, истечение срока и т. п.). Нет данных — писать «не сообщается», не выдумывать. Для ранее внесённых строк колонки «Кого сменил» и «Причина» заполнять при уточнении (новой пометкой).
