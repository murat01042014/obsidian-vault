# Прочти меня первым (расширенная база)

Это **расширенная версия** личной базы знаний — для тех, кому базовой папки
стало мало. Здесь появляются папки-зоны, файл текущего состояния и отдельный
протокол завершения сессии. Принцип тот же: ИИ-агент читает папку при входе
и работает, опираясь на твои файлы, а не на выдумки. Чат умирает — файлы остаются.

## Чем отличается от базовой

| база | расширенная |
|---|---|
| все файлы в корне | папки-зоны: `plans/`, `projects/`, `people/`, `decisions/` |
| планы в `today.md`/`week.md` | те же файлы, но в `plans/` |
| — | `status.md` — текущее состояние: что в работе, что застряло |
| протокол завершения внутри инструкции | отдельный файл `session-end.md` |
| 6 принципов | 10 принципов |

## Что куда и зачем

| файл / папка | что это | зачем |
|---|---|---|
| `README.md` | этот файл | объяснение для человека; агенту он не нужен |
| `HOME.md` | карта базы | первая страница: кто ты и где что лежит |
| `status.md` | текущее состояние | что в работе, что застряло и почему; агент читает каждую сессию |
| `principles.md` | правила | 10 правил работы с базой |
| `session-end.md` | протокол завершения | что агент делает в конце каждой сессии |
| `CLAUDE.md` | инструкция агенту | читается автоматически, если работаешь в Claude |
| `AGENTS.md` | та же инструкция | то же для других инструментов (Codex и др.); для Gemini скопируй в `GEMINI.md` |
| `plans/today.md` | план на сегодня | агент помогает вести день и отмечает сделанное |
| `plans/week.md` | план на неделю | горизонт побольше |
| `projects/` | по файлу на проект | один файл — одна тема: работа, ремонт, поездка |
| `people/` | по файлу на человека | карточки: кто это, контекст, договорённости |
| `decisions/` | принятые решения | файл `ГГГГ-ММ-ДД-о-чём.md`; чтобы не пересматривать решённое |
| `_archive/` | завершённое | закрытые проекты и старые планы; из живых файлов сюда не ссылаемся |

Почему инструкция в двух файлах: содержание одно, читатели разные — каждый
инструмент ищет своё имя. А `HOME.md` — карта самого знания, её читает кто
угодно. **Сменишь ИИ — заменишь только файл-инструкцию; знание останется твоим.**

## Как начать

0. Открой эту папку в Obsidian («Open folder as vault») — увидишь файлы и
   граф связей (иконка «Graph view» слева).
1. Открой агента (Claude Code / Claude Desktop / Codex / Gemini) в этой папке.
2. Попроси: «Проинтервьюируй меня и заполни файлы базы» — или заполни
   плейсхолдеры `[в скобках]` руками.
3. Проверь глазами, что агент написал. Неверно — скажи поправить.
4. **Каждую сессию заканчивай**: «Заверши сессию по `session-end.md`».

## Как база растёт

- Новый проект → новый файл в `projects/` + строка в `HOME.md`.
- Важный человек в делах → карточка в `people/`.
- Принял решение → файл в `decisions/` с датой; агент сошлётся на него,
  когда вопрос всплывёт снова.
- Проект закончился → файл переезжает в `_archive/`, строка из `HOME.md`
  удаляется.
- Правило можно менять: не нравится, как агент работает, — поправь
  `principles.md` или инструкцию, а не объясняй заново в каждом чате.
