# Personal — кадровые документы

Здесь ведём кадровые документы ЦАКФ.

## Структура

- [Кадры/Сотрудники.md](Кадры/Сотрудники.md) — реквизиты сотрудников для приказов (ФИО, должности, номера ИТД, статус, рабочие годы).
- **[Приказы/](Приказы/)** — как оформляется каждый тип приказа (шаблоны, боилерплейт RU/EN, нюансы, примеры из архива):
  - [00 — Общие правила](Приказы/00%20—%20Общие%20правила.md) — подписанты, нумерация, язык, юр. основания, роль Верховного Попечителя.
  - 01 — Отпуск очередной · 02 — Отпуск без содержания · 03 — Отзыв из отпуска · 04 — Перенос отпуска
  - 05 — Командировка · 06 — Возложение обязанностей
  - 07 — Приём и назначения · 08 — Увольнение и расторжение ТД
  - 09 — Премии · 10 — Организационные приказы
  - 11 — Заявления работников · 12 — Согласования Верховного Попечителя

Разобрано по архиву `D:\приказы\` (сентябрь 2026). Сам архив разложен по 15 папкам
`01_… … 15_…`; откат раскладки — `D:\приказы\_ВЕРНУТЬ_КАК_БЫЛО.ps1`, карта перемещений — `_manifest.csv`.

## Правило сессий

- Каждая сессия по кадрам ведётся и сохраняется под названием
  **«Personal — ГГГГ-ММ-ДД»** (дата сохранения).
- В конце сессии сохраняем её под этим названием.
- В следующий раз продолжаем **в новой сессии с чистой историей** —
  предыдущую не переоткрываем.
