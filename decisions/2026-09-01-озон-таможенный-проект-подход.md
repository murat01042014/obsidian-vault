# Подход к проекту ЦАКФ по таможенному оборудованию для ОРВ/ГФУ

Дата: 2026-09-01

Связано: [[Концепция]], [[Уточнения и позиция]], [[01 — Международные обязательства]].

**Решил:**
- ЦАКФ разрабатывает проект «оснащение таможенных постов РК оборудованием для
  идентификации ОРВ и ГФУ».
- Канал финансирования — **ГЭФ** (Казахстан не действует по ст. 5 Монреальского
  протокола → Многосторонний фонд недоступен). Через агентство ГЭФ — ЮНИДО или ПРООН.
- **Сначала Казахстан**, все крупные таможенные посты. Регион ЦА — рабочий поток
  в ходе реализации, отдельная заявка (фаза 2).
- ЦАКФ **не вносит денежное со-финансирование** — только в натуре.
- Команда: 7 штатных (ядро, надзор) + проектная команда по договорам ГПХ под
  средства проекта.
- Институциональный путь: МИД РК → письмо в МЭПР РК (ожидается осенью 2026) →
  (МЭПР + МИД) → международная организация → определение ЦАКФ держателем процессов.
  Разграничение ролей с МЦЗТИП (ЦАКФ — таможня/правоприменение/регион; МЦЗТИП —
  политика/Кигали/ГФУ в промышленности).
- Вознаграждение ЦАКФ — **«вариант 2»: институциональные накладные 8%** от прямых
  затрат проекта (административно-управленческое сопровождение силами штата).
- Ставки национальных работников в смете — **−30%** к первоначальной оценке,
  указаны **брутто (до удержания)** налогов и взносов.
- Отдельная статья бюджета — **МТО команды проекта** (~94 тыс. USD).
- Параллельный трек — **аккредитация ЦАКФ как проектного агентства ГЭФ** (главный
  долгосрочный доход фонда).
- Бюджет: грант ГЭФ ~2,6 млн USD, полная стоимость ~4,7–5,0 млн; срок ~4,5–5 лет.

**Почему:**
- РК — не ст. 5 (проверено по Секретариату по озону), МФ закрыт, ГЭФ — единственный
  профильный канал; у РК есть история финансирования ОРВ через ГЭФ.
- У ЦАКФ нет свободных средств — модель должна оплачивать команду из проекта с
  подготовительной фазы.
- Национальный проект быстрее и служит пилотом; институциональное закрепление
  ЦАКФ в РК уже идёт.
- Накладные 8% — законная и защищаемая форма вознаграждения; прибыль на грант
  недопустима и вредит отношениям с МЭПР/МИД.

**Что отверг:**
- Многосторонний фонд Монреальского протокола — недоступен Казахстану (не ст. 5).
- Прибыль/маржа ЦАКФ на грантовые средства — снимут при проверке ГЭФ, репутационный
  риск.
- Прежний уровень ставок (был на 30% выше) — снижен по решению Мурата.
- Региональный проект сразу — отложен на фазу 2 (условие МЭПР/МИД: сначала
  национальное определение ЦАКФ).
- Расчёт на возобновляемый IS-грант — это инструмент только МФ, у РК его нет.
