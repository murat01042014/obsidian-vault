# 2026-10-05 — Политики Фонда утверждает Верховный попечитель / Попечительский совет

**Решение (Мурат):** в новой редакции Положения внутренние политики Фонда утверждаются Верховным попечителем / Попечительским
советом по представлению Управляющего совета.

**Разграничение (моё предложение, Мурат согласился):**
- политики (кадровая, антикоррупционная, ПОД/ФТ, раскрытия информации, взаимодействия со стейкхолдерами, по проектам) —
  ВП / Попечительский совет по представлению УС (Положение 3.2 д));
- стратегия развития — ВП (3.5 е));
- правила, порядки, инструкции, в т.ч. Правила закупок, — Управляющий совет (8.7);
- переходная норма: политики, утверждённые УС раньше, действуют до утверждения ВП / Попечительским советом.

Меняет решение 01.10 (8.7 «всё утверждает УС, кроме стратегии») — [[2026-10-01-положение-усиление-вп-без-адм-функций]].

**Где отражено:** СТ по Положению v7, СТ по ВНД v2 (концовки 4 политик + Кадровая политика, раздел 13), новые редакции
Положения RU/EN (3.2 д) / 3.2 (e), 8.7) — `D:\Устав\8 Новые документы — до подписания\1 Изменения в Устав, Положение и ВНД\`.

**Дальше:** после вступления новой редакции — резолюция ВП об утверждении действующих политик (одним документом).
