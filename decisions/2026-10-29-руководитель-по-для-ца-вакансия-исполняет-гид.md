# 2026-10-29 - Руководитель ПО для ЦА: штатная единица 1 400 000, вакансия, обязанности исполняет ГИД без доплаты

**Решение (Мурат):** в штате есть должность Руководителя Проектного офиса для ЦА с окладом 1 400 000 гросс; пока она вакантна, ПО для ЦА
возглавляет ГИД – это входит в его должностные обязанности, оклад Руководителя и доплата за совмещение ему не выплачиваются.

**Основание:** оклады и вознаграждение ГИД как члена УС – только с одобрения ВП (пп. ж) п. 3.5, разд. 9 Положения), сам себе ГИД доплату не назначает;
доплата 30% по Кадровой политике (разд. 7-1 п. 4) – за замещение временно отсутствующего, для ГИД при руководстве ПО для ЦА – прямое исключение.

**Где:** Положение о ПО для ЦА п. 5.1 (RU/EN), Кадровая политика 7-1 п. 4 и СТ по ВНД, штатка/ШР (31 ед.), резолюция ГИД (29 ед., 28,9 млн),
протокол № 13 и СЗ, структура. Скрипт `D:\Устав\_исходники\ruk_po_ca_vakansiya_2026-10-29.ps1`; копии до правки – `D:\Устав\_копии до правок\до «вакансия Руководителя ПО для ЦА» (2026-10-29)`.
Отменяет часть решения 23.10 (ГИД руководит ПО для ЦА «без отдельной единицы») – [[decisions/2026-10-23-кононец-советник-по-для-ца-гид]].
