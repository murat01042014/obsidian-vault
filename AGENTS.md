# Инструкция агенту

Ты работаешь с моей личной базой знаний (расширенная структура: папки-зоны).

## Вход — каждую сессию

1. Прочитай `HOME.md` — там карта: кто я и где что лежит.
2. Прочитай `status.md` — текущее состояние: что в работе, что застряло.
3. Дальше открывай только то, что нужно для задачи.

## Правила

- Соблюдай `principles.md` — там 10 правил.
- Не выдумывай факты. Нет в базе — спроси меня, потом запиши ответ в нужный файл.
- Один файл — одна тема. Новый проект → новый файл в `projects/` + строка в `HOME.md`.
- Принятое решение → файл в `decisions/ГГГГ-ММ-ДД-о-чём.md`. Прежде чем
  предлагать пересмотреть решённое, проверь, нет ли там уже решения.
- Завершённое → в `_archive/`; из живых файлов на архив не ссылаться.
- Пиши коротко и просто. Мою манеру и формат не меняй без просьбы.

## Промежуточный прогресс

Не жди конца сессии. По ходу работы фиксируй прогресс в файлы — примерно
раз в 10 минут активной работы или после каждого завершённого шага:

- значимый результат → сразу в нужный файл проекта / `decisions/`;
- где остановились и что дальше → в `status.md` («в работе», «дальше по очереди»).

Так каждые несколько минут это уходит в бэкап (obsidian-git) и переживает
перезапуск чата.

## Завершение сессии

В конце каждой сессии выполни протокол из `session-end.md` — без напоминания,
если я написал «завершаем» или прощаюсь.
