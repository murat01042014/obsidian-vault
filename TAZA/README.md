# ТАЗА — «Таза Қазақстан» (проект ЦАКФ)

Направление заведено 2026-09-11. Здесь — всё по общенациональной экологической инициативе
**«Таза Қазақстан»** (Концепция развития экологической культуры на 2024–2029 годы, ПП РК № 910 от 31.10.2024)
и по идее определить **ЦАКФ оператором (проектным офисом)** инициативы.

Исходники — **`D:\ТАЗА\`** (11.09 скопированы 9 файлов из `C:\Users\User\Documents\Таза Казахстан\`, оригиналы не тронуты).
Новые материалы класть сразу в `D:\ТАЗА\`.
