# Критерии успешности идей и проектов для «Таза Қазақстан»

2026-09-22. Файл Мурата: `D:\ТАЗА\Критерии успешности идей.docx`. **По этим критериям оцениваем все новые идеи и проекты ТК** (задача на потом).

## Критерии (как в файле)

1. **Вовлечённость общества** — одобрение инициативы обществом: молодёжью, средним и старшим поколением.
2. **Капиталоёмкость** (в файле — «фондоёмкость»; Мурат просит писать «капиталоёмкость») — сколько денег требует.
3. **Экономический эффект.**
4. **Эко-образование, эко-воспитание, эко-культура.**
5. **Продолжительность** — устойчивость идеи/проекта во времени.
6. **Инновационность проектов.**
7. **Технологичность** (в файле — «Технологическая»).
8. **Позитивное влияние на здоровье.**
9. **Пиаро-пригодность**; в итоге — пиар-эффект.
10. **Чистый бизнес** — открытость данных, экологичность производств и хоз-адм. деятельности, инновационность.

## Как оценивать (мой вариант, согласовать с Муратом перед первой оценкой)

- Шкала по каждому критерию: 0 — нет, 1 — слабо, 2 — средне, 3 — сильно.
- **Капиталоёмкость — обратная:** чем дешевле, тем выше балл (3 — почти без затрат, 0 — очень дорого).
- Итог — сумма (максимум 30) + короткое обоснование по каждому критерию; при равенстве баллов выше та идея,
  у которой сильнее «вовлечённость общества» и «продолжительность» (учитывая позицию Мурата: результат для жителя, а не мероприятия — см. [[decisions/2026-09-22-таза-шесть-направлений-результат-вместо-мероприятий]]).
- Веса критериев — по решению Мурата (пока все равны).
