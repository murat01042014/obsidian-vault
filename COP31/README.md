# COP31 — 31-я Конференция ООН по климату

Анталья (Турция), 9–20 ноября 2026. Двойное председательство: хост — Турция,
переговоры ведёт Австралия. Pre-COP — Фиджи/Тувалу, 5–8 октября.

Роль ЦАКФ — программный офис содержательной части **Странового павильона РК**
(по межведомственному плану МЭПР). Исходные материалы МЭПР: `D:\КОП31\`.

## Правило сессий

- Каждая сессия по COP31 ведётся и сохраняется под названием
  **«COP31 — ГГГГ-ММ-ДД»** (дата сохранения).
- В конце сессии сохраняем её под этим названием.
- В следующий раз продолжаем **в новой сессии с чистой историей** —
  предыдущую не переоткрываем.

## Правило: проверять обновления в начале сессии

**В начале каждой сессии по COP31 — сразу, без напоминания — проверить источники
ниже и сказать, что изменилось с прошлого раза.** Материалы обновляются часто
(программа, состав делегации, правила), и работать по старым данным нельзя.

1. **Программа павильона** — Google Sheets, актуальная вкладка (на 16.09 — `gid=762780698`;
   более ранние: `950667652`, `939052912`):
   https://docs.google.com/spreadsheets/d/1FaFCvHh9Z76S9HIL6nPIPJ2ZI_YBybpUkjkhk9Nk23U/edit
2. **Список делегации (LOP)** — Google Sheets, `gid=23112348`:
   https://docs.google.com/spreadsheets/d/1dqnjX6g4MZjGGX99QmU7JqBiXqJ6RcDu/edit
3. **Презентация ключевых экопроектов / наполнение павильона** — Google Docs:
   https://docs.google.com/document/d/1nUvoY_g2etmfPksMjUkHT_9PeW8fgPu_/edit
4. **Тематические дни председательства** — cop31.tr:
   https://cop31.tr/news-detail/thematic-days-announced-2026
5. **Правила приёма заявок в павильон** — gov.kz (МЭПР, документ 1054433):

Что смотреть в первую очередь: сессии ЦАКФ и их время; строки CACF в LOP (кто едет

Техническая заметка: экспорт Google-документов идёт через редирект на
`googleusercontent.com` — ссылку из ответа нужно запросить повторно.
Форматы: таблицы `…/export?format=csv&gid=<gid>`, документы `…/export?format=txt`.
