# ПРООН — что уже есть в базе

> ЧЕРНОВИК — в работе. Собрано 2026-09-10 из других направлений; своих
> материалов по ПРООН пока нет.

## OZON (таможенное оборудование ОРВ/ГФУ)

- **ГЭФ 9788** «HCFC Phase-out in Kazakhstan» — агентство ПРООН, исполнитель
  Минэнерго; ~4,6 млн USD грант + 36,8 млн со-фин. Был компонент по таможне.
  **Отменён 02.11.2021** (CEO Endorsement не подан ~18 мес.).
  Подробно: [[OZON/Концепция v2 (краткая)]].
- ПРООН — запасной вариант агентства ГЭФ для проекта ЦАКФ; приоритет — ЮНИДО
  (ведёт ГЭФ 11881). Вопрос «ЮНИДО или ПРООН» открыт:
  [[OZON/Уточнения и позиция]], вопрос 9.
- Ранее: мобильные детекторы ОРВ на таможне (ЮНЕП + ПРООН, координация КГД МФ РК).
- Контактов в ПРООН у ЦАКФ нет (по состоянию на 09.2026).

## COP31 (павильон РК)

- В программе павильона: **2 подтверждённых мероприятия ПРООН**, ещё ПРООН — в
  проработке; приоритет — средний. См. [[COP31/01 — Доп. материалы МЭПР (2026-09-02)]].
- ПРООН упоминается в концепции сессии по Каспию/осушенному дну.
  См. [[COP31/02 — Новые материалы МЭПР (2026-09-04)]].
